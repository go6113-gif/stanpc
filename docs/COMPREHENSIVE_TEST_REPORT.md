## 📐 단계별 처리 분석

### Step 1: 원본 이미지 다운로드
```
입력: eBay 검색 결과
출력: 1200×800px RGB 이미지
특징:
  • 가로형 사진 (가로가 더 길음)
  • 색상: Stray Kids(보라), AESPA(주황), IVE(파랑)
  • 파일크기: 약 10-13KB/개
```

### Step 2: 멤버 감지 및 크롭
```
입력: 1200×800px 원본
출력: 400×267px 크롭된 이미지
처리:
  • Haar Cascade 기반 얼굴 감지
  • 중앙 영역 자동 감지 (신뢰도: 0.85)
  • 패딩 포함 안전 크롭
  
종횡비: 400 ÷ 267 = 1.497
```

### Step 3: 종횡비 보정 및 패딩

**종횡비 계산**:
- 원본: 1.500 (현재 비율)
- 목표: 0.649 (표준 포토카드)
- 차이: 1.500은 목표값보다 훨씬 큼 → 수직 패딩 필요

**패딩 적용**:
- 방향: 수직 (위/아래)
- 방식: Letterbox (이미지 왜곡 방지)
- 색상: 흰색 (255, 255, 255)
- 결과: 389×600px (임시)

### Step 4: 최종 리사이징

**리사이징**:
- 입력: 389×600px (패딩 후)
- 출력: 259×400px (표준 크기)
- 보간: LANCZOS4 (고품질)
- 종횡비: 0.648 (목표: 0.649, 편차: 0.001)

**검증**:
- 종횡비 편차: 0.001 ✅ (허용: ±0.05)
- 최종 크기: 259×400px ✅
